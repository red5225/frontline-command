# Art and asset notes

The map is rendered procedurally by scripts/map_view.gd: a custom mountain-country silhouette, generated Voronoi-like region cells, ownership fills, route lines, unit markers, labels, grid, and cartographic accents.

brand/frontline-emblem.svg is an original vector emblem created for this project. It is not copied from a real military or government insignia.

There are no paid asset packs, remote runtime assets, copyrighted map tiles, or required external art downloads. The geography is fictional and illustrative; generated region cells are not real administrative borders.
