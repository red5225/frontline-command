# Roadmap

## Current prototype
- 34-region fictional theater
- Procedural cell boundaries and vector cartography
- Selectable groups and route orders
- Rival AI expansion
- Abstract control contests and occupation progress
- Resource and supply loop
- Pause, speed control, event log, region intelligence panel
- Data validation and Godot headless CI/package workflow

## Next improvements
- Save/load scenarios and configurable starting positions
- Additional fictional maps and region graph authoring tools
- Scenario editor for ownership, supply, and strategic values
- More nuanced diplomacy, public services, and regional stability systems
- Optional map labels, accessibility scaling, and alternate color palettes
- Desktop exports for Windows, Linux, and macOS once export templates are configured
